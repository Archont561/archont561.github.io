## Selected repositories

These summaries use public GitHub repository metadata. Visit the source repository for current status and installation instructions.

* [qgis-agent-harness](/docs/projects/qgis-agent-harness): A harness that scores GIS-agent artefacts: one QGIS runtime, nine geoprocessing operations, three ways of exposing them, one oracle. Code for an MSc thesis in geoinformatics.
* [qgis-sdk](/docs/projects/qgis-sdk): Python-first SDK and TypeScript QWebEngineView bridge for building typed, testable QGIS 4 plugins
* [CloudCompare-conda](/docs/projects/cloudcompare-conda): Cross-platform Conda packaging for CloudCompare 3D point-cloud and mesh processing.
* [ODM-conda](/docs/projects/odm-conda): Unofficial, modular OpenDroneMap conda packaging — Pixi-managed rattler-build recipes for ODM CPU components (dem2points, fpcfilter) targeting a prefix.dev channel.
* [pixi-sandbox](/docs/projects/pixi-sandbox): Cloneable, verifiable environment packs for Pixi projects.
* [universe](/docs/projects/universe): Rust toolkit for building and publishing self-hosted universes of software, data, models, and skills—with offline-ready distribution.
* [staged-recipes-submit](/docs/projects/staged-recipes-submit): Reusable GitHub Action and Python CLI to validate Conda recipes (recipe.yaml / meta.yaml) and open idempotent PRs to conda-forge/staged-recipes.
* [bun-test-utils](/docs/projects/bun-test-utils): General-purpose test extension for the Bun test runner covering unit, integration, and e2e tests — Playwright-style typed fixtures composed with test.extend(), with scopes and LIFO teardown, plus BDD, property-based testing, snapshots, HTTP record/replay, and browser testing.
* [playtest](/docs/projects/playtest): Playwright-style testing framework for Rust with dependency-injected fixtures, strict LIFO teardown, property-based testing, and fluent BDD scenarios
* [artifactspec](/docs/projects/artifactspec): An early-stage framework for describing and producing visual artifacts with an agent-friendly language.
* [skills](/docs/projects/skills): Plain-directory Agent Skills with a stdlib-only Python dispatcher — install with npx skills add, run via archont561.
* [PyShellForge](/docs/projects/pyshellforge): A Python-native DSL and AST-based compiler for generating clean, readable, production-ready shell scripts.
* [clifacet](/docs/projects/clifacet): A Rust library for command-line presentation modes.
