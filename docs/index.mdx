## Start here

This directory is the canonical source for understanding, using, configuring, and operating the portfolio software.
It serves both human readers and AI agents. Project descriptions reflect public repository metadata; they do not guarantee feature completeness.

* [Guides](/docs/guides): install, run, and deploy the site.
* [Concepts](/docs/concepts): static hosting, content provenance, and AI access.
* [Reference](/docs/reference): commands, configuration, and schemas.
* [Architecture](/docs/architecture): system boundaries and design decisions.
* [Development](/docs/development): contribution, testing, and documentation policy.
* [Project directory](/docs/projects): selected public repositories and source links.
* [About](/docs/about): editorial boundaries and public contact information.

## Source of truth

Edit existing canonical documents when behavior changes. Do not copy setup or reference instructions into parallel guides.
See the [documentation policy](/docs/development/documentation) for ownership, validation, and the definition of done.
