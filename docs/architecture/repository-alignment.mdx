## Scope and limits

Scanned 19 public owner repositories on November 9, 2026. Seventeen exposed readable recursive Git trees; two returned HTTP 409 and appear empty. No private repositories or repository settings were inspected.
The checked-in `data/repository-audit.json` records commit/tree identities, file inventories, selected files read, and retrieval errors.
These observations describe configuration, not proof that upstream CI succeeds.

## Shared baseline

Across all 19 listed repositories, including the two unavailable trees:

* `pixi.toml`: 13 repositories.
* `pixi.lock`: 13 repositories.
* `lefthook.yml`: 11 repositories.
* `AGENTS.md`: 12 repositories.
* `bun.lock`: 10 repositories.
* `.alint.yml`: 6 repositories.
* `.vale.ini`: 6 repositories.
* `biome.json`: 5 repositories.

`qgis-sdk` is the closest documentation reference: purpose-oriented docs, Bun, Pixi tasks, Biome, alint, Vale, markdownlint-cli2, lychee, actionlint, convco, Lefthook, and immutable action references.
`rude-clean-code` also demonstrates marker-preserving agents-md maintenance. These are observed patterns, not a claim of one universal template.

## Migration context

This audit is historical evidence from the original profile repository, not a
current configuration inventory for this monorepo. The site and documents
were migrated into `apps/portfolio` and root `docs/`; repository maintenance is
now implemented in Bun under `packages/tools`. Consult the
[architecture](/docs/architecture) and [command reference](/docs/reference) for
the current setup. The original evidence and pinned source links remain below.
