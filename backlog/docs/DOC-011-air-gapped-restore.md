# DOC-011: Air-gapped restore runbook (pixi-sandbox)

**Status:** draft · **Milestone:** TASK-001 · **Decisions:** D-009

## Restore

```bash
./scripts/restore.sh        # generated by pixi-sandbox init (v0.9.0 stamp)
```

Derives `sandbox/<bundle>-<platform>` from `pixi-sandbox.toml`, fetches the
transport ref if absent, unpacks to `.pixi/.restore-transport`, runs
`pixi-sandbox restore --force`. Git + POSIX shell are the only prerequisites.

## Operator knobs

| Variable | Effect |
| --- | --- |
| `PIXI_SANDBOX_FETCH=skip` | never fetch; fail closed when the ref is local-only |
| `PIXI_SANDBOX_USER_TOOLS=skip` | leave HOME/shell profiles untouched (shared hosts) |
| `PIXI_SANDBOX_BRANCH` | explicit transport branch |
| `PIXI_SANDBOX_BUNDLE` | disambiguate when several bundles cover the platform |

## Integrity

- `scripts/restore.sh` and the sandbox workflows are **generated** —
  regenerate via `pixi-sandbox init`, never hand-edit (D-009).
- CI runs `pixi-sandbox init --check` to catch drift.
- Known limit (upstream `pixi-sandbox#128`): pypi wheels may report integrity
  warnings after re-install (uv rewrites dist-info); environments remain usable.
